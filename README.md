# 气泡识别（Bubble image recognition）

沸腾气泡视频的检测与计数研究项目（`video1.mp4`：1350×1080 @25fps）。

## 现状（2026-10-16）

- 两段式检测流水线已完成：时间高通增强 → 逐像素分类器 → 候选块 CNN（v1/v2/v3），
  脚本在 `src/`、`tools/`；
- 找气泡没问题（召回 0.8~0.93），但受素材画质限制，前端误检多（精度约 0.5），
  **暂不支持全自动计数**——结论：瓶颈在原始视频画质，不在模型；
- 下一步预案：换更好素材重拍后按 `任务交接_413恢复.md` 第 7 节流程继续。

## 运行

```powershell
python cli.py analyze video1.mp4 --out results   # 基础分析
python -X utf8 tools/train_patch_cnn.py          # 训练候选块模型（v3）
python -X utf8 tools/review_overlay.py           # 出复核图
```

## 大文件说明

视频素材、导出帧（`标注工具/frames/`）、训练数据集与输出（`results/`、`results_train/`）、
探针中间产物均不入库，可由脚本重新生成。
